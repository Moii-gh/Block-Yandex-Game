<h1 align="center">Block Yandex Games</h1>

<p align="center">
  Легкое расширение для Chromium-браузеров, которое блокирует открытие страниц Яндекс Игры.
</p>

## Что делает расширение

Block Yandex Games использует `declarativeNetRequest` из Manifest V3 и блокирует переходы на Яндекс Игры:

```text
https://yandex.ru/games/*
```

Расширение не содержит фоновых скриптов, не собирает данные и не требует широких разрешений на доступ к сайтам.

## Возможности

- Блокировка основного перехода на страницы Yandex Games.
- Минимальная структура без лишнего JavaScript.
- Manifest V3.
- Собственный логотип и набор иконок для браузера.
- Простая настройка правила через `rules.json`.

## Установка

1. Скачайте или клонируйте репозиторий.
2. Откройте страницу расширений в браузере:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - другой Chromium-браузер: раздел управления расширениями
3. Включите режим разработчика.
4. Нажмите **Load unpacked** / **Загрузить распакованное расширение**.
5. Выберите папку проекта.

## Проверка

После установки откройте:

```text
https://yandex.ru/games/
```

Браузер должен заблокировать переход по правилу расширения.

## Настройка правила

Основное правило находится в `rules.json`.

Чтобы изменить блокируемый адрес, обновите поле `urlFilter`, затем перезагрузите расширение на странице управления расширениями.

## Ограничения

- Сейчас блокируется только `https://yandex.ru/games/*`.
- Зеркала, другие домены и встроенные ресурсы не блокируются, если они не совпадают с правилом.
- Лицензия в репозитории не указана.

## Дисклеймер

Проект не связан с Яндексом и не является официальным продуктом Яндекса. Изображение в README и иконках является сгенерированным визуальным ассетом для демонстрации блокировки Яндекс Игр.
